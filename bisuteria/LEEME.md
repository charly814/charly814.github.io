# TPV Bisutería · 饰品店收银系统

打开 `bisuteria/index.html`(上线后:`https://charly814.github.io/bisuteria/`)。
初始 PIN:管理员 `1111`、员工 `0000` —— **请第一时间在 设置 → 员工账号 里修改**。
界面可切换 中文 / Español;小票、发票等打印件固定为西班牙语。

## 功能

| 模块 | 内容 |
|---|---|
| 🛒 收银 | 扫码枪 / 搜索 / 点击商品;手输商品;单品折扣、整单折扣;挂单;现金(自动算找零)、刷卡、Bizum、会员余额、代金券/礼品卡,可混合付款;F9 收款 |
| 🧾 单据 | 小票(factura simplificada,含 IVA 明细)、**礼品小票**(不显示价格)、重打;整单或部分**退货**(退现金 / 刷卡 / 余额 / 代金券);**发票**(连续编号 F-年份-0001,退货自动生成更正发票 R-) |
| 👥 会员 | 会员卡号和条码、电话、生日提醒、备注;**充值**(可设置充值赠送档位);**积分**(消费得分、积分抵扣);等级(按累计消费自动升级,等级折扣、积分倍数);余额/积分流水;手动调整 |
| 🎁 礼品卡/代金券 | 出售礼品卡;退货代金券;可分多次使用,有效期 |
| 💍 商品 | 货号、条码(自动生成)、中西文名称、分类、售价、成本、库存、最低库存提醒、照片;入库 / 损耗 / 盘点;库存流水;**打印价格条码标签**(A4 标签纸或标签打印机);CSV 导入导出 |
| 🏷️ 促销 | 买 N 付 M(3x2…)、百分比折扣;按全场 / 分类 / 单品;起止日期;收银时自动生效 |
| 💶 钱箱 | 开班备用金、现金存入/支出、X 报表、日结 Z(清点现金、差额)、历史日结 |
| 📊 报表 | 净销售额、单数、客单价、毛利、退货、优惠、充值;按日 / 商品 / 分类 / 付款方式 / 员工;IVA 汇总;CSV 导出 |
| ⏱ 员工 | **打卡考勤**:PIN 界面不用登录就能打卡上下班;登录时提醒打卡;今日在岗情况;按日 / 周 / 月统计工时;漏打卡标红;管理员补录和更正(记录操作人和原因,不能删除只能作废);打印每人可签字的考勤表(Registro de jornada,art. 34.9 ET);CSV。**提成**:每人提成 %、按分类单独比例;每单可选销售员;退货自动扣回;提成报表、明细、打印、CSV。**权限**:每个员工 19 项权限逐项勾选,店员 / 店长模板,最大折扣;没有权限时负责人输入 PIN 临时授权 |
| ⚙️ 设置 | 店铺和小票信息、积分规则、会员等级、充值赠送、纸宽 58/80mm、数据备份/恢复 |

扫码框同时识别:商品条码、会员卡、代金券、小票上的条码(直接打开该单据办理退货)。

## 打印

用浏览器打印。把 80mm(或 58mm)热敏小票机设为默认打印机;想要不弹出打印对话框,
用 Chrome 的 `--kiosk-printing` 启动参数。钱箱接在小票机上,在打印机驱动里设置「打印时开钱箱」。

## 重要说明

1. **数据保存在这台电脑的浏览器里**(IndexedDB),不联网也能用,但不会自动同步到其他电脑。
   请每周在 设置 → 数据备份 下载备份文件;清除浏览器数据或换电脑时用它恢复。不要用无痕模式。
2. **VERI\*FACTU**:西班牙要求开票软件符合 Reglamento de facturación(RD 1007/2023)的期限即将生效。
   本软件**尚未**实现 Veri\*Factu(记录哈希链、向 AEAT 发送、小票二维码),也没有厂商责任声明。
   请向您的 gestor 确认适用于您的日期;在那之前可正常用于会员、库存、收银管理。
